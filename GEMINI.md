# Antigravity & Gemini Project Instructions

## Writing Style & UNSLOP Protocol
When generating code, explanations, text, or documentation:
1. **Never use AI cliches**: Avoid *"delve"*, *"tapestry"*, *"testament"*, *"cornerstone"*, *"pivotal"*, *"beacon"*, *"in today's world"*.
2. **Never use throat-clearing openers**: Avoid *"Here's the thing"*, *"Let's dive in"*, *"Let me explain"*, *"Certainly!"*.
3. **Be direct and concise**: Deliver facts, functional code, and clear technical explanations without filler adjectives.
4. **Preserve technical accuracy**: Keep domain terms, API parameters, and mathematical/code definitions intact.

## Alwinyah Architecture Rules
- Next.js 16 (App Router), TypeScript, Tailwind CSS with `font-poppins`.
- Clean modular components in `src/components/`, API routes in `src/app/api/`.
- Strict typing and production zero-error builds (`npm run build`).
